### What's new
- **Card rows fit the window.** Rows on Discover show as many whole cards as fit, and the cards grow and shrink with the window, so none are cut off at the edge. **Show all** next to a row's title opens the whole list; **Show fewer** folds it back. It only appears when some cards are hidden.
- **More top titles.** Top on MyAnimeList now reads the first 200 titles of each list instead of 50.
- **Smaller windows.** Continue reading fits the window like the other rows. In a narrow window the top bar keeps the tab icons but hides their names (shown on hover), so the search box isn't cut off any more.

### Fixes
- **Smoother scrolling.** Pictures no longer stop arriving for a moment while you scroll a chapter. Discover doesn't search in the background while you're reading, repeat searches are much faster, and cleaning the picture cache and saving the series list no longer hold up the app.
